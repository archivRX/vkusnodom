# ВкусноДом — сайт рецептов под ключ
24 рецептов, отдельные страницы, SEO-разметка (Schema.org), sitemap, тёмная тема, поиск, фильтры.

## Как выложить в интернет (бесплатно, 15 минут)
1. Зарегистрируйтесь на github.com
2. Создайте репозиторий: New repository -> имя "vkusnodom" -> Public -> Create
3. Нажмите "uploading an existing file" и перетащите ВСЕ файлы из этой папки (кроме этого README)
4. Settings -> Pages -> Branch: main -> Save
5. Через 2 минуты сайт будет жить по адресу: ваше-имя.github.io/vkusnodom

## Как добавить рецепт
1. В data.js добавьте блок в массив RECIPES (по образцу существующих).
2. В index.html скопируйте блок <a class="card"...>...</a> и поменяйте тексты.
3. Скопируйте любой файл из папки recipe/, переименуйте и поменяйте тексты внутри.
Подробно каждый шаг можно разбить со мной в чате.

## Монетизация, когда будет трафик
- Яндекс РСЯ (partner2.yandex.ru) — реклама, от ~100 посетителей в день
- Партнёрская программа Яндекса — ваши ссылки на Браузер/приложения
- Партнёрки маркетплейсов: посуда, кухонная техника (реферальные ссылки)

## Заменить ссылки на сайт
В sitemap.xml и robots.txt замените vash-sayt.ru на ваш реальный домен.
