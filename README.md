# ВкусноДом

Кулинарный сайт с 24 проверенными домашними рецептами, поиском по ингредиентам и списком покупок.

## Возможности
- Поиск по названию и ингредиентам
- Фильтры по категориям, сортировка по времени
- Избранное (сохраняется в браузере)
- Список покупок с копированием в буфер (общий для всего сайта)
- Отметки шагов на страницах рецептов
- Тёмная тема
- Случайный рецепт

## Запуск
Откройте `index.html` или загрузите на GitHub Pages. Данные рецептов — в `data.js`.

## Структура
- `index.html`, `style.css`, `data.js` — главная страница
- `recipe/` — 24 страницы рецептов
- `robots.txt`, `sitemap.xml` — SEO
