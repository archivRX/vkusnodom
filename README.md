# ВкусноДом

Кулинарный сайт с 24 проверенными домашними рецептами, поиском и фильтрами. Готовая база для монетизации.

## Функционал
- **Поиск:** Ищет по названию блюда и ингредиентам.
- **Фильтры:** Группирует рецепты по категориям (Супы, Десерты и т.д.).
- **Список покупок:** Можно добавлять ингредиенты из рецептов в общий список, копировать его или очищать.
- **Адаптивность:** Корректно отображается на мобильных телефонах и ПК.

## Как запустить
1. Клонируйте репозиторий.
2. Откройте `index.html` в браузере (или загрузите на GitHub Pages).
3. Данные рецептов хранятся в файле `data.js`.

## Технологии
- HTML5
- CSS3
- Vanilla JavaScript
